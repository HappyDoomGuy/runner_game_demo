# NEON RUNNER

Мобильный 2D горизонтальный скролл-шутер в киберпанк / нуар стиле.

## Управление

| Жест | Действие |
|------|----------|
| **Tap** | Стрелять |
| **Swipe ↑** | Прыжок через препятствия |

На десктопе: `Space` / `↑` — прыжок, `J` / `X` / `F` — стрельба.

## Запуск

```bash
cd demo
python3 -m http.server 8765
```

Открой на телефоне (та же Wi‑Fi сеть): `http://<IP-компа>:8765/`  
Или локально: [http://localhost:8765/](http://localhost:8765/)

Лучше в **landscape** (альбомной) ориентации.

## Геймплей

- Персонаж бежит автоматически
- Враги: ходящие стрелки, дроны, летающие роботы
- Неоновые ящики/барьеры — перепрыгивать свайпом вверх
- 3 жизни, счёт за убийства, дистанция
